# 🎨 PabloCovers

**PabloCovers** es una aplicación web minimalista y ligera (desarrollada en un único archivo HTML) diseñada para crear portadas y miniaturas 1:1 con calidad de estudio para playlists de **Spotify, YouTube Music, Apple Music, Tidal** y más.

Cuenta con un sistema de previsualización en tiempo real basado en Canvas, optimizado especialmente para su uso en dispositivos móviles.

---

## ✨ Características principales

- **Diseño System Editorial:** Estética limpia con colores planos saturados, subtítulos flotantes, títulos en tipografía gruesa y la característica píldora inferior de interfaz.
- **Galería 3D Integrada:** Acceso rápido a una selección de elementos gráficos 3D (copas, discos, hielos, fuego, etc.) listos para usar sin necesidad de subir nada.
- **Removedor de Fondos con IA Local:** Incluye procesamiento de inteligencia artificial directamente en el navegador (`@imgly/background-removal`) para eliminar el fondo de cualquier foto propia al instante y sin enviar datos a servidores externos.
- **Personalización Completa:**
  - Selector de colores de fondo con paleta de tonos populares predeterminados.
  - Sincronización o personalización independiente del color de acento y del título principal.
  - Textos editables en tiempo real.
- **Exportación en alta calidad:** Genera y descarga instantáneamente la miniatura en formato PNG (1000x1000 píxeles).

---

## 🚀 Uso local rápido

Al estar construida completamente en un único archivo (HTML, CSS y JS combinados), no requiere instalación de dependencias ni servidores Node.js.

1. Clona o descarga el repositorio.
2. Abre el archivo `index.html` directamente en cualquier navegador web moderno (o utilízalo mediante herramientas de desarrollo local como Live Server).

---

## 🛠️ Tecnologías utilizadas

- **HTML5 Canvas API** para el renderizado gráfico y exportación de imágenes.
- **CSS3** (Variables CSS, Flexbox, diseño responsive mobile-first).
- **JavaScript Vanilla (ES6+)** con carga dinámica de módulos.
- **@imgly/background-removal** para la segmentación de imágenes por IA en el cliente.
- **Microsoft Fluent 3D Emojis** (vía CDN jsDelivr) para los recursos gráficos de la galería.
